Medidas de assimetria e curtose

Assimetria: É o grau de desvio da simetria de uma distribuição. Ela é positiva para as distribuições assimétricas à direita, negativa para aquelas assimétricas à esquerda e para distribuições simétricas o seu valor é zero.

Curtose: Indica o grau de achatamento de uma distribuição, tomando como referência a curva normal.
