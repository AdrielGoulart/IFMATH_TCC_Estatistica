Apresentação de Dados




O objetivo da apresentação de dados é exibir dados de uma pesquisa.

Toda a característica que, observada em uma unidade de pesquisa, pode variar de unidade para unidade é chamada de Variável. Exemplos: idade, nota das provas, entre outras. As variáveis são subdivididas em qualitativas e quantitativas.

Variáveis Qualitativas: As variáveis qualitativas (ou categóricas) são aquelas que representam uma classificação dos indivíduos que pode ser nominal ou ordinal.

  • Variáveis nominais: não existe ordenação dentre as categorias. Exemplos: cor dos olhos, fumante/não fumante, doente/sadio.
  • Variáveis ordinais: existe uma ordenação entre as categorias. Exemplos: escolaridade (1º, 2º, 3º graus), estágio da doença (inicial, intermediário, terminal).

Variáveis Quantitativas: As variáveis quantitativas são aquelas que podem ser descritas por números, sendo estas classificadas entre contínuas e discretas.

  • Variáveis discretas: a variável é avaliada em números que são resultados de contagens. Exemplos: número de filhos, número de bactérias por litro de leite.
  • Variáveis contínuas: a variável é avaliada em números que são resultados de medições e, por isso, podem assumir valores com casas decimais. Exemplos: massa (balança), altura (régua).
