Propriedades

O gráfico de barras apresenta dados categorizados em barras retangulares horizontais nos quais os retângulos correspondentes a cada categoria é proporcional ao número de observações na respectiva categoria. O gráfico de barras é utilizado para realizar comparações entre as categorias de uma variável qualitativa.

Desenhamos um retângulo alinhado à esquerda, com base unidades e altura 1.
