Propriedades

O gráfico de colunas apresenta dados categorizados em barras retangulares verticais nos quais os retângulos correspondentes a cada categoria é proporcional ao número de observações na respectiva categoria. O gráfico de colunas é utilizado para realizar comparações entre as categorias de uma variável qualitativa ou quantitativa discreta.
