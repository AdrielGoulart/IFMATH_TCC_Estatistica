Polinômio

É uma expressão algébrica inteira em que há apenas multiplicação entre números e letras. Essas letras devem ser expressas na forma de potência com expoentes naturais (0,1,2,3,...).
As operações envolvendo polinômios podem ser divididas em: Valor Numérico, Adição e Subtração e Multiplicação.

Valor Numérico

Diz respeito ao valor obtido quando analisamos uma função polinomial (ou polinômio), com um determinado valor para a variável x (ou qualquer outra variável presente no polinômio).

Como resolver um Valor Numérico?

O propósito de se calcular o valor numérico de um polinômio é definir um valor para cada uma das incógnitas do polinômio, e realizar os devidos cálculos afim de se obter um valor final para a expressão.

Exemplo 1:
Sendo:
Polinomio = 2x^2 + 5x − 2
x = 2

Solução:

Passo 1:

Substituímos as variáveis pelo seu valor numérico respectivo.

Passo 2:

Realizamos a potência dos termos.

Passo 3:

Realizamos a multiplicação dos termos.

Passo 4:

Por fim, realizamos a soma e a subtração dos termos restantes.

Adição e Subtração

Para efetuarmos a adição (e subtração) de polinômios devemos agrupar termos semelhantes. Um termo é considerado semelhante a outro, quando possuem a mesma parte literal.

Como resolver uma Adição ou Subtração?

O propósito de se calcular a adição ou subtração entre dois polinômios é a de agrupar o máximo de elementos possíveis que sejam semelhantes, a fim de obter uma nova expressão como resultado final.

Exemplo 1 (Adição):
Sendo:
Polinomio A = 3x^2 - 2x
Operação = + (Adição)
Polinomio B = 9 + 4x^2 + 4x

Solução:

Passo 1:

Equação Inicial.

Passo 2:

Removendo os parênteses dos polinômios.

Passo 3:

Ordenando os termos.

Passo 4:

Soma dos termos semelhantes.


Exemplo 2 (Subtração):
Sendo:
Polinomio A = 6y^5 - 5y + 4
Operação = - (Subtração)
Polinomio B = 2y^5 - 8y + 4

Solução:

Passo 1:

Equação Inicial.

Passo 2:

Aplicando a regra de troca de sinais em operações prioritárias, em duplas negações ou em somas de números negativos. E, removendo os parênteses dos polinômios.

Passo 3:

Ordenando os termos.

Passo 4:

Soma dos termos semelhantes.


Multiplicação

Para realizarmos essa operação, multiplicamos coeficiente com coeficiente e parte literal com parte literal de cada monômio, considerando sempre a regra de sinais*. Para isso, utilizamos a propriedade distributiva**, e caso haja termos semelhantes (com mesma parte literal) devemos reduzi-los.

*Regra de sinais: Se os dois números multiplicados possuírem o mesmo sinal, o resultado será positivo. E se os dois números possuírem sinais diferentes, o resultado será negativo.
**Propriedade distributiva: Essa propriedade indica que dois ou mais termos presentes numa expressão de soma ou subtração multiplicada por outra, é igual à soma ou à diferença da multiplicação de cada um dos termos da adição ou da subtração pelo número. Ou ainda, pode ser definida pela expressão algébrica: a x (b + c) = a x b + a x c ou a x (b - c) = a x b - a x c

Como resolver uma Multiplicação?

O propósito de se calcular a multiplicação, é a de agrupar os elementos, sejam eles semelhantes ou não, a fim de se obter uma nova expressão como resultado final.

Exemplo 1 :
Sendo:
Polinomio A = x^2 - 25
Polinomio B = 3 - x

Solução:

Passo 1:

Equação Inicial.

Passo 2:

Aplicando a propriedade distributiva, onde cada elemento do primeiro termo é multiplicado por cada um dos elementos do segundo termo.

Passo 3:

Multiplica-se os coeficientes, considerando a regra dos sinais, e para as variáveis, somam-se os expoentes pela propriedade das potências.

Passo 4:

Ordenando os termos.
