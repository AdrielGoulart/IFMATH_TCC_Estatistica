Os números naturais

Os números naturais são representados por todos os números positivos, começando pelo zero, e eles são utilizados para indicar uma contagem, medida ou código. O símbolo que representa esse conjunto é N.
N* é o símbolo utilizado para não incluir o elemento zero no conjunto, definido como conjunto dos números naturais não-nulos.

Números pares e ímpares

Todos os números naturais podem ser definidos como par ou ímpar. Um número é definido como par quando ele é divisível por 2 e o resto dessa divisão resultar em 0. Um número é definido como ímpar se o resto dessa divisão for diferente de 0. O zero é comumente adicionado ao conjunto dos números pares.
Conjunto dos números pares = {0,2,4,6,8,10...}
Conjunto dos números ímpares = {1,3,5,6,7...}
