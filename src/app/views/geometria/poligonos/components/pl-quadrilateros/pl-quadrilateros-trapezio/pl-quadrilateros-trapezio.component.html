Trapézio

Propriedades:

O trapézio é um quadrilátero (quatro lados) que possui um par de lados paralelos: Os lados paralelos dos trapézios são chamados de bases. A base que possui maior medida é chamada de base maior e a que possui menor medida é chamada de base menor.

É um quadrado, pois todos os lados possuem a mesma medida e os ângulos internos são retos.
É um retângulo, pois possui os lados congruentes dois a dois e os ângulos internos são retos.
É um paralelogramo, pois possui os lados paralelos dois a dois.
  • Trapézio Isósceles são aqueles que possuem lados não paralelos congruentes (com a mesma medida).
