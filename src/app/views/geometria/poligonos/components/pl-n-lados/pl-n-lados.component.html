Polígonos

Clique na tela para definir os vértices do polígono:

Clique com o botão esquerdo para adicionar um vértice
Clique e arraste com o botão esquerdo para mover um vértice
Clique com o botão direito para remover um vértice.

Propriedades:

Polígonos são linhas fechadas formadas apenas por segmentos de reta que não se cruzam.

Este não é um polígono pois não é uma figura fechada.
